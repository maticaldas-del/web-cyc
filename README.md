# Página Web CYC

Panel de negocio **CYC** (PWA): métricas ML, arqueo, pedidos y puntaje del mes.

- App: `index.html`
- Service worker: `sw.js`
- Manifest PWA: `manifest.webmanifest`
- Ícono: `icon.svg`

Usa Firebase (auth + base de datos) y Chart.js. Producción en Netlify; vista previa en GitHub Pages.
